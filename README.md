# qnet-runner

큐넷 빈자리 감시기의 **실행기**. 워크플로와 진입점만 있고 조회 경로는 없다.

## 왜 저장소가 갈렸나

깃헙 액션 실행 시간은 **워크플로가 도는 저장소** 기준으로 과금된다.
공개 저장소는 무제한 무료, 비공개는 월 2,000분 한도다.
감시기는 접수 창이 열린 날 촘촘히 돌아야 해서 비공개만으로는 한도를 넘긴다.

반대로 큐넷 좌석 조회 경로는 "접수 창이 열려 있는 48시간 안에만 알아낼 수 있는"
지식이라 이 프로젝트의 사실상 유일한 진입장벽이다. 공개할 수 없다.

→ **실행은 여기(공개)서, 코드와 데이터는 비공개 저장소에서.**
   워크플로가 배포 키로 코어를 체크아웃해 얹는다.

## 구성

```
.github/workflows/watch.yml   매시 05분 + 수동 실행
run.py                        코어를 sys.path 에 얹고 watch.main() 호출
```

필요한 시크릿: `CORE_SSH_KEY`(코어 저장소 배포 키), `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`.

수집 대상은 로그인 없이 공개된 페이지뿐이고, 요청 빈도는 보수적으로 잡았다.
